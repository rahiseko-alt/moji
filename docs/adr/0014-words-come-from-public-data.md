# 単語は公的データから選ぶ

市販の「N5単語集」の類を写せば120語はすぐ揃う。そうしない。

漢字1字や単語1語に著作権は無いが、**どの語を選び、どう並べたか**には著作権が
生じる（著作権法12条・編集著作物）。出版社の単語集はまさにその選択と配列で
できている。出典を書くか書かないかの問題ではなく、写した時点で同じ扱いになる。
学校の名前と校章を載せて配るものなので、ここは避ける。

そこで、単語は次の公的データから選ぶ。

- **国立国語研究所『日本語教育のための基本語彙調査』**（報告78, 1984）約6,900語。
  CC BY 4.0、商用可。日本語教育のために選定された語彙なので、母体として最も近い。
  https://mmsrv.ninjal.ac.jp/bvjsl84/
- **文化庁「生活上の行為の分類」** 小分類48。文部科学省ウェブサイト利用規約
  （CC BY 4.0互換、商用可、出典表示）。ここから12の場面を選ぶ。
  https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/94276701_01.pdf
- **学年別漢字配当表** 第1学年80字。同上。

## Consequences

日本語能力試験に公式の語彙リストは存在しない（2010年の改定で『出題基準』が
非公開になった）。したがって「試験に出そうな単語」は推定であって、公式の裏付けは
取れない。実際にはN5相当の語は日常語なので、基本語彙と大きく重なる。

基本語彙調査は1984年の調査で、スマホ・ネットの語を含まない。12場面のうち
「スマホやネット」の単語だけは裏取りができず、こちらで出して先生が判断する。

JMdict（CC BY-SA 4.0）は語義が豊富だが、SA条項が派生物に及ぶため、単語のデータには
混ぜない。BCCWJ の頻度表は研究・教育目的に限られるため使わない。

選んだ単語そのものは、先生が見て足し引きする。これは編集著作物の複製ではなく、
このプロジェクト自身の選択である。

# 曲がっている画は、曲がっていないと正解にしない

「い」をわざと雑に書いても合格になった。判定が見ていたのは、画の
書き出しと書き終わりの位置・全体の向き・道からのはみ出し量の3つで、
画の途中がどう曲がっているかは見ていなかったためである。

「い」は2画とも左上から右下へ流れる。1画目のはね（下で折り返して
右上へ上がる部分）だけが「い」を「い」たらしめている。定規で引いた
2本の線でも、両端の位置も向きも合ってしまう。これでは練習にも
テストにもならない。

そこで、画ごとに「お手本の曲がりをどれだけ残したか」を見る。お手本が
まっすぐな画には曲がりが無いので、この項目は問わない。

## Consequences

手のふるえは速い揺れで、はねや曲がりはゆっくりした曲がりである。
比べる前に軌跡をならすことで、前者は消え後者は残る。ふるえで不正解に
なることは増えない。

画がどれだけ位置をずれてよいかは、升目に対する固定値ではなく、その画
自身の長さに対する割合にした。従来は短い画でも22（升目の約5分の1）まで
許していたため、「い」の2画目は自分の長さの半分以上ずれても正解だった。

出荷しているすべての字（172字）で測った結果、定規で引いた字が合格する
割合は48%から33%に、曲がりを7割失った字は66%から33%に下がった。
残る33%は、お手本自体がまっすぐな画だけでできている字（一、日など）で、
これらは定規で引くのが正しい書き方である。

一方、正しい書き方のうち「指で書いたような画（少し短く、少しずれ、
ふるえる）」が合格する割合は92%から86%へ下がった。厳しくした分の代償で
ある。実機の筆跡をまだ1本も持っていないため、この数値は人工的に作った
ブレに対するものでしかない。

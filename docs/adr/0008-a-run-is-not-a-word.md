# まとめ書きは単語ではない

学生が字をえらぶ画面で複数の字を選び、選んだ順に書けるようにした。並べた字は
単語（意味のあるひとまとまり、1〜4字）と見た目は似ているが、別のものとして
扱う。単語は場面ごとに用意された学習内容で、字数に上限があり、書く対象では
ない字（小学1年配当漢字以外）をお手本のまま含むことがある。まとめ書きは
学生がその場で作る並びで、上限がなく、書く対象しか含まない。

## Considered Options

まとめ書きを単語の一種として実装することも考えた。画面を1つにできるが、
単語の決まり（4字まで・場面に属する・書かない字を含む）が学生の選択に
持ち込まれ、どちらの規則が効いているのか読めなくなる。並べて書くという
見た目の共通点だけで、規則はほとんど重ならない。

# 単語が必要とするかなは全部教える

清音のかな46字ずつだけを教えていた。濁点「が」・半濁点「ぱ」・小さい字「っ」
「ゃ」・長音符「ー」は「清音と同じ画に印が付くだけで、新しく覚える字ではない」
という理由で外していた。

120語の単語データを作って、それが成り立たないことが分かった。

- 「でんしゃ」「ともだち」「かばん」「ごみ」「コンビニ」「アルバイト」——
  留学生が最初に使う語ほど、これらの字を含む。
- 国語研の基本語彙の見出し語5,666語を、かなで書いたとき——清音だけで書けるのは
  2,554語（45%）。濁点・半濁点・小さい字・長音符を足すと5,422語（96%）になる。
  残りは元データの記号（「-」「/」など）で、書けない字が理由ではない。
- 場面「ごみ」に「ごみ」という単語を入れられない、という状態が実際に起きた。

印を付ける画も、学生にとっては引く画である。「が」は5画、「ぱ」は4画として
筆順データを持ち、他の字と同じように判定する。

## Consequences

字数は172字から243字になる（ひらがな81・カタカナ82・漢字80）。筆順データは
178KB から 250KB へ。KanjiVG に全字そろっているので、出どころは変わらない。

五十音表は11列から、ひらがな18列・カタカナ19列になる。濁音・半濁音は
が行・ざ行・だ行・ば行・ぱ行の5列として清音の右に続け、小さい字と「ー」は
母音の段を持たないので、同じ高さの列に並べるだけにする。

「ー」はカタカナにだけ入れる。ひらがなの語で長音符を使うのは例外的な書き方で、
学校で教える書き方ではない。

印の画は短い（「が」の濁点は11.6、字の1画目は99.1）。位置の許容は短い画でも
20を下限にしているため、濁点を本来の位置から多少ずらしても正解になる。
判定の甘さとして残る。既知の問題として引き継ぎメモに置く。

# 字は升目の位置で判定する（0010 を撤回する）

設計記録 0010 では、答え合わせの前に書いたもの全体をお手本に重ね直し、升目の
どこに書いたかを問わないことにした。理由は「テストには点線もお手本も無いので、
書く位置が自然とずれる」であった。テストを封印した（0012）ことでその理由が
消えたため、重ね直しをやめ、升目の位置で判定する形に戻す。

点線とお手本が常に出るようになったので、どこに書くかは升目が示している。
そこからずれた字を正解にすると、升目そのものの意味が無くなる。

## Consequences

画の書き出しと書き終わりが、お手本からどれだけ離れてよいかの下限を 10 から 16 に
上げた。点線があっても指で書けば数ミリはずれるためである。出荷している172字で
測ると、字全体がまっすぐ 12（升目は109）ずれても全字が正解のままで、13 から
崩れはじめ（28字が不正解）、14 で 37% まで落ちる。14 で落ちるのは端の位置ではなく
道からのはみ出しによるもので、そこを緩めると形の判定そのものが甘くなるため、
緩めていない。

まっすぐ 20 ずらしても、172字のうち31字は正解のままである（く・し・つ・一・十 など、
長い画1本でできた字）。画がずれてよい量はその画自身の長さの45%で、上限が22だからで、
その上限は長い画が5分の1手前で止まっても通すためにある。上限を16に下げると
20 のずれは全字が不正解になるが、代わりに「指で書いたような字」の合格率が
87%から71%に、「5分の1手前で止まった字」が65%から43%に落ちる。位置で咎めるために
正しい書き方を落とすのは本末転倒なので、上限は22のままにした。

1画だけ書いて送信した場合も、その画は升目の位置で判定される。0010 では「書いた
もの全体」として重ね直していたため、どこに書いても位置は問われなかった。

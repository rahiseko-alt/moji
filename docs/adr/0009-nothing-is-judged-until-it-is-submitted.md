# 画はその場で突き返さず、送信してから答え合わせする

当初の練習は、間違った画をその場で赤くして取り消し、同じ画を書き直させていた。
間違った形を手に覚えさせないためだったが、実機で使うと「書いた画がすぐ消える」
としか見えず、判定がわずかに厳しいだけで練習が成立しなくなった。書いている最中に
正誤を挟むと、学生は1画ごとにアプリの顔色をうかがうことになる。

そこで、お題を最後まで書かせ、送信してから答え合わせすることにした。筆跡は残り、
間違った画は赤くなり、間違いのあった字はナビが1画目から正しい書き方を走らせる。

## Consequences

ナビと「正解を教える」が同じ部品になった。出番が2つあるだけで、動きは同じ
（画の始点から終点へ朱色の印が動く）。練習とテストの違いも、点線・お手本・
先回りのナビを出すかどうかと、答え合わせをその場でするか最後にまとめてするか、
だけになった。

学生が間違った形を最後まで書き切ってしまう点は、承知のうえで受け入れている。
書き終えた直後に正しい書き方を見せ、やり直しをすぐ選べることで補う。

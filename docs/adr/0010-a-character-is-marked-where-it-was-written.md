# 字は書かれた場所で判定する

テストには点線もお手本も無い。学生は升目のどこかに字を書き、その位置は
お手本と少しずれる。1画ずつ升目の絶対位置で比べていたため、字としては
正しく書けていても全画が不正解になっていた。このアプリが教えているのは
筆順と形であって、升目のどこに書いたかではない。

そこで、答え合わせの前に、書いたもの全体を中央どうしでお手本に重ね直す。
そのうえで画ごとに向き・形・長さ・位置を見る。字の中での画の位置は今までどおり
判定されるが、字そのものを升目のどこに置いたかは問わない。

## Consequences

1画しか書かずに送信した場合、その1画が「書いたもの全体」になるため、
どこに書いても重ね直されて位置は問われない。画数がそろうほど、字の中での
位置のずれが効いてくる。これは意図した振る舞いで、部分的にしか書いていない
ものを位置で咎めても学習にならない。

大きさは補正していない。小さく書きすぎた字は、画の位置と長さで不正解になる。

# 単語のお題は、升目を横に並べて1回で書く

単語データ（120語）は入ったが、学生はそれを書けなかった。お題は1字だけで、
書く画面の升目も1つしか無かった。

単語のお題は、**字数ぶんの升目を横に並べ、1回の送信でまとめて判定する**。

- 升目は1字につき1つ。4字の語なら4つ。読む順に左から並べる。
- 画は、**書かれた升目の字**に対して判定する（ADR 0013 を升目の列に広げただけ）。
  「日本」の2つ目の升目に「日」を書いたら、それは不正解。
- お題が一発正解になるのは、**すべての升目が正解だったとき**だけ。
  1つの升目を間違えれば、その語は不正解。
- 送信のあと、答えのナビは**間違えた升目だけ**を走る。
  1字ずれただけの語で、合っている3字まで答えを見せられるのはおかしい。
- 書いている最中のナビは、**まだ画が足りていない最初の升目**に出す。
  語は左から書くので、そこが学生のいる場所である。先の升目に線を引いても
  ナビは動かない。

## Considered Options

**1つの升目に1字ずつ、次へで送る**案もあった。画面は今のままで済むが、
学生は語を書いたのではなく字を4回書いたことになる。語の練習は、
4つの字が並んで1つの語に見えることまで含む。

**1つの升目に語全体を書かせる**案は、座標が字の109四方の正方形に定義されている
という前提（ADR 0003）を壊す。お手本も判定も全部書き直しになる。

## Consequences

書く画面の状態は「升目ごと」になる。判定の入口（writing-session）は、
画を受け取るときにどの升目かを一緒に受け取る。字1つのお題は「升目1つの列」
として同じ道を通り、数え方（一発正解・合計）は以前とまったく同じ。

お題全体をひとまとめにした一覧（全升目の判定を1本に連結したもの）は持たない。
升目ごとの一覧が本物で、2つ持てばいつか食い違う。

筆順データを持たない字が単語に入ると、その升目は「0画の升目」になり、
何も書かなくても正解として数えられてしまう。いまの単語データは全部の字が
書く対象なので起きない（単語データの試験がそれを守っている）。
書く対象でない字をお手本として出す仕組みは、必要になってから作る。

升目は、高さいっぱいか、幅を升目の数で割ったぶんか、小さいほうに合わせる。
横向きのスマホ（844×390）で4字の語が1画面に収まることを確認した（1升目199×199）。
書く画面の行は番号で固定する。結果の一列は出ていないとき grid の行から外れるので、
固定しないと升目がその行に落ちて高さが0になる。

まとめ書きで単語と字を混ぜて選べる。お題の並びに規則は要らない（ADR 0008）。

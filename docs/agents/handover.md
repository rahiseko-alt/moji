## 2026-09-14 まとめ書き（文字の複数選択）を作った

**決めたこと**

- 文字はタップで選び、選んだ順に番号が付く。「はじめる」で選んだ順に1字ずつ書く
- 上限なし。種類（ひらがな・カタカナ・漢字）をまたいで選べる。同じ字は1回だけ
- 1字書き終わるごとに「次へ／やり直す」。やり直しても数え方は最初の結果のまま
- 最後の字を書き終えると、その字に重ねて合計と字ごとの○×を出す
- テストは途中で結果を出さず、書き終えてからまとめて出す
- 「ぜんぶ」でいま見ている種類の全字を選び、もう一度押すと外れる
- ホームは表紙のまま。捨てるものがあるときだけ確認を出す（選んだ字／あと◯字）
- まとめ書きは語とは別物として扱う（設計記録 0008）
- かなは五十音表の形に並べる。表紙の絵は試用版でも出るようにした

- 利用者に試用版でまとめ書きを触ってもらう

## 2026-09-13 実機で試して採点を調整し、不具合を3件直した

**決めたこと**

- 設定を待たずに実機で触れるよう、同じ中身を会話から開ける試用版として公開した。
  学生に配る正式な公開先とは別で、利用者だけが見られる
- 採点の閾値は勘で動かさない。いろいろな書き方が実際にどんな数値になるかを先に測り、
  正解にすべき書き方と不正解にすべき書き方の境目に置く
- その境目をテストに固定した。正解側（完璧・手ぶれ・強い手ぶれ・少し中心外れ）と
  不正解側（1割のずれ・45度の傾き・2割手前で終わる・曲線を直線で書く）の両方を検証する
- 突き返した画は列から外して別に持つ。位置で覚えていると、その間に画が増えたときに
  別の画を消してしまう
- 最初に触れた指以外は受け付けない。手のひらが触れると以降が無視されるため
- 書き終わったら入力そのものを止める。判定されない線が残らないようにするため

**次にやること**

- 利用者に試用版を再度触ってもらい、今度は厳しすぎないかを確認する
- GitHub の Settings > Pages で公開元を「GitHub Actions」に設定する（利用者の操作。
  スマホではブラウザを「PC版表示」に切り替える必要がある）
- PR #1 を `main` に取り込む
- #9 以降は `/grill-with-docs` を通してから実装する

**未解決の問題**

- 判定が厳しすぎないかは未確認。緩める場合も境目のテストごと動かす
- ナビが実機で見えているかを確認できていない

## 2026-09-24 単語を1場面100・計1200にし、困る漢字を足した

**決めたこと**

- 単語は12場面×100＝1200。約半分は国語研の基本語彙、残りは公的資料が「読めないと困る」と示す語
  （注意書き・標識、申込書の欄、役所や病院の書類、災害の語）から選んだ（ADR 0017）
- 1年生の外の漢字は、常用漢字表の中からだけ、単語の中でだけ書く。漢字の表は80字のまま
- 単語は看板や書類でふつうに書かれる形で書く（でんしゃ→電車）。常用漢字でない字はかな（せき）
- 判定はきびしさ3で固定。判定の欄と、画ごとの判定の表示はやめた
- 札（場面・単語・結果）は、ほんの少しだけ透かす
- 1場面100の単語は1画面に収まらないので、この画面だけ下へ送って見る

**次にやること**

- 利用者が試用版（https://claude.ai/artifact/MeAcARuzoEQ4s7pfSLCGTB）を実機で確かめる
- 場面の名前（左上）を消すか、ひらがな・カタカナ・漢字の表の選んだ字も塗りつぶすか、利用者の答えを待つ
- 変更提案 #16 を `main` に取り込む（利用者の合図を待つ）
- 取り込み後、#18〜#22、#24〜#34 を閉じる

**未解決の問題**

- 筆順データが約2.5MB（圧縮して約0.9MB）になった。遅い回線では最初の表示が遅い
- 足した745字の筆順は、画数だけ標準と突き合わせた（違ったのは「餅」1字で、かなにした）。
  筆順そのものは1字ずつ確かめていない
- スマホやネットの語には確かな公的出典がほとんど無い（学校の判断）

## 2026-09-24 字えらびと書く画面を実機に合わせて直した

**決めたこと**

- 答え合わせを求めるボタンは「確定」。流れは「確定」→「次へ」。用語集も「確定」に揃えた
- 字えらびの上の帯のボタンは、4言語とも同じ大きさ。選んだ単語の札は朱色で塗りつぶす
- 単語の札に意味の説明は出さない。読みは書いた形と違うときだけ出す
- 場面と単語の札は画面いっぱいに広げず、必要な大きさで真ん中に並べる
- アプリは画面全体ではなく、与えられた高さに収める（試用版の見出しの下で升目が切れていた）
- 場面の札を開いたとき左上に出る「コンビニ」などは、開いている場面の名前

- 利用者が試用版（https://claude.ai/artifact/MeAcARuzoEQ4s7pfSLCGTB）を実機で確かめ、

- 場面の名前（左上）を消すかどうか、利用者の答えを待つ
- ひらがな・カタカナ・漢字の表で選んだ字も塗りつぶしにするか、利用者の答えを待つ
- 変更提案 #16 を `main` に取り込む（利用者の合図を待つ）

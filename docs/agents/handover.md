## 2026-09-09 引き継ぎメモの仕組みを追加

**決めたこと**

- 引き継ぎメモを `docs/agents/handover.md` に置き、会話開始時に直近分を自動で読み込む
- 書く場面は「何かを完成させて提出した時」と「方針を決めた時」の2つ。私が自動で判断して書く
- 書式は3項目（決めたこと／次にやること／未解決の問題）。理由や触ったファイルは書かない
- 追記したら作業中の枝にコミットして送る。承認待ちで止めない。書くたびに1行だけ報告する
- 置き場所は公開のままとする（利用者の判断）

**次にやること**

この順序で行うこと。順序を入れ替えると作業が消える。

1. この変更（`claude/repo-structure-workflow-review-voguzy`）を `main` へ取り込む
2. 既定の枝を `main` に切り替える。GitHubの画面で Settings → General → Default branch。
   これは利用者による操作が必要（AI側の道具では実行できない）
3. 取り込み済みであることを確認したうえで、不要になった枝を削除する
   （`claude/matt-pocock-skills-setup-bq9kp7`、および取り込み後の作業枝）
4. 次のセッションの冒頭で、この仕組みが実際に自動で読み込まれたかを確認する

**未解決の問題**

- 現状、案内役（`next-step`）は `main` にあるが既定の枝には無い。引き継ぎメモは `main` にもまだ無い。
  よって上記1と2の**両方**を終えるまで、新しいセッションではどちらも読み込まれない
- 既定の枝の切り替えは、AI側の道具では実行できない。利用者による画面操作が必要
- 保存先に置いた自動実行の設定が、初回に利用者の承認を求めるかどうかは未確認
